# `examples/`

Files to try VisionaryX with. Lumen Ridge Orchard Co-op is **fictional**: every name,
figure and date in these files was made up for the demo.

| File | Use it in | Try asking |
|---|---|---|
| `lumen_ridge_annual_report_2025.pdf` | PDF Chat (4 pages) | *What was the total apple harvest in 2025?* |
| `lumen_ridge_cold_storage_plan.docx` | PDF Chat (headings and a table) | *What does the cooling system cost?* |
| `lumen_ridge_harvest_chart.png` | Image Query | *Which year had the biggest harvest, and how much did it grow on the year before?* |

Upload the PDF and the Word file **together** and ask *"When will the new cold-storage
building open, and what will it cost?"*: the answer needs both files, and the sources
under it name each one (a page of the PDF, sections of the Word file).
