# VisionaryX 2.0.1 (notes; not tagged)

Changes on `main` since [2.0.0](v2.0.0.md) (tag `v2.0.0`, commit `150448f`). This version
is not tagged or released yet.

## Accuracy: the app says only what the code does

- **Model labels.** Answers come from a Gemini model chain with automatic fallback
  (`gemini-2.5-flash`, then `gemini-3.5-flash-lite`, then `gemini-3.1-flash-lite`), so the
  landing page no longer names one fixed model ("Gemini 2.5 Flash", "Gemini Vision"). Each
  answer still shows which model wrote it ("Answered by …"). (#18)
- **Chunking** is described as recursive character chunking (1,000 characters, 150
  overlap), not "semantic". (#18)
- **Citations** are described as built from the retrieved chunks, deduplicated by file,
  page and section, rather than as "page-level". (#18)
- **Image Query** no longer promises a "structured analysis": Gemini answers your question
  about the image, or describes it in detail when there is no question. The guide lists the
  formats the uploader accepts (JPG, PNG, WebP, GIF). (#18)

## Backend

- **Index storage uses one encoding.** New FAISS indexes are stored as the codec's JSON
  text instead of being base64-encoded once more (about 25% smaller). Indexes stored by
  2.0.0 (base64 of the JSON) and before it (base64 of a pickle, read as data only) still
  load; this was checked live with a 2.0.0-format index after the deploy. (#14)
- **Dead PDF fallback removed.** One of four extraction strategies read an attribute pypdf
  pages do not have, so it never ran; the three real strategies remain. (#14)
- **Dependencies:** pydantic 2.14.1, pydantic-settings 2.16.2, faiss-cpu 1.15.1 (#13);
  uvicorn 0.54.0, python-multipart 0.0.32, langchain 0.3.30, langchain-community 0.3.27,
  pypdf 4.3.1, python-docx 1.2.0, Pillow 11.3.0 (#17). Locks regenerated with uv's
  `--universal` markers.

## Frontend

- react-hot-toast 2.6.1, @vitejs/plugin-react 4.7.0, autoprefixer 10.6.2 (#15).

## Repository

- Documentation: a RAG deep dive with a worked example, the architecture and security
  model, `SECURITY.md`, `CONTRIBUTING.md` (with the dependency policy and planned major
  upgrades), a docs index, and `scripts/rag_walkthrough.py`.
- Dependabot: weekly grouped minor and patch updates per ecosystem; semver-major updates
  ignored and planned deliberately (#12).
- Removed the outdated pre-revival mock-up page and image (#11).

**Tests:** 135 backend (was 123 at 2.0.0) and 56 frontend (was 53).
